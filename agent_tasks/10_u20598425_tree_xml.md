# u20598425 - syntax tree and XML

## Objective

Provide the parser with a safe tree-building API and produce a deterministic,
validated, browser-readable `tree.xml`.

## Owned paths

```text
src/spl_frontend/tree.py
src/spl_frontend/xml_writer.py
tests/unit/test_tree.py
tests/unit/test_xml_writer.py
tests/integration/test_tree_xml.py
```

Do not implement lexer token recognition, grammar parsing or the CLI in these
files.

## Implementation checklist

- Implement `NodeKind`, `TreeNode` and `SyntaxTree` from the shared contract.
- Allocate IDs deterministically, starting from one for each new tree.
- Permit exactly one root and forbid a parent on it.
- Add inner and leaf nodes only under an existing parent.
- Append child IDs in grammar/input order.
- Keep parent and child relationships symmetric.
- Provide safe read access by node ID and deterministic node iteration.
- Implement full validation before XML writing.
- Reject missing root, multiple roots, invalid parent, dangling child,
  asymmetric links, duplicate child reference, cycle and unreachable node.
- Implement a provisional XML schema in one writer module so it can be changed
  without touching the parser.
- Escape XML contents correctly.
- Serialize deterministically.
- Write to a temporary sibling file, flush/close it and replace the final file
  only after the tree and XML are complete.
- Remove or invalidate stale output before a new compilation can be mistaken
  for success.

## Required tests

- Empty tree fails validation.
- A valid root-only or minimum supported tree validates according to the
  agreed nullable representation.
- IDs are unique and repeatable across fresh trees.
- Child order is preserved.
- Each structural corruption is detected individually.
- Token text containing XML-sensitive characters is escaped.
- Identical trees produce byte-identical XML.
- A simulated write failure does not publish partial output.
- Written XML can be parsed again with the Python XML library.

## Handoff to parser owner

Provide short examples for:

```python
root = tree.add_root("SPL_PROG")
program = tree.add_inner("P", root.node_id)
leaf = tree.add_leaf(":", program.node_id)
```

The parser owner must never allocate IDs or edit `child_ids` directly.

## Acceptance

- Shared tree contract is implemented without parser-specific logic.
- Validator covers all required invariants.
- `tree.xml` contains every node exactly once.
- Unit and integration tests pass.
- XML-format assumptions are clearly marked as provisional until confirmed.
